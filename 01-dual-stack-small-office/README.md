# Project 1: Dual-Stack Small Business Network

## Objective

To design and configure a basic small-business network that provides IPv4 and IPv6 connectivity between an administration endpoint and an internal server.

## Business scenario

Emetonjor Solutions Ltd requires a reliable internal network for office administration and internal services. The network must support IPv4 and IPv6 addressing as part of a future-ready dual-stack design.

## Skills demonstrated

- IPv4 addressing and subnetting
- IPv6 addressing and prefixes
- Router interface configuration
- Basic switch connectivity
- Default gateway configuration
- Endpoint IP verification
- IPv4 and IPv6 troubleshooting
- Network documentation
